ZEHRART — GITHUB PAGES MÜŞTERİ DEMOSU

Bu klasör yalnızca statik müşteri demosudur. .bat / Node.js / admin paneli gerekmez.

Yükleme:
1. GitHub'da yeni PUBLIC repository oluşturun (örnek: zehrart-demo).
2. Bu klasörün İÇİNDEKİ dosyaları repo köküne yükleyin.
3. Repository > Settings > Pages.
4. Build and deployment > Source: Deploy from a branch.
5. Branch: main, Folder: / (root) > Save.
6. GitHub size Pages linkini açın.

Önemli: ZIP dosyasını tek dosya olarak repo içine atmayın. ZIP'i açıp index.html repo kökünde olacak şekilde yükleyin.
